# GasWise — Project Reflection

## What I Got Wrong at the Start

Initially, I thought that tracking cooking duration, burner usage, and flame intensity would be enough to accurately predict when an LPG cylinder would run out. During development, I realized that these factors only provide an approximate cooking-usage score. Without actual gas measurements or reliable refill history, predicting the exact amount of LPG remaining is difficult.

## What I Would Cut

If I built GasWise again, I would focus on a simpler solution with a cooking-usage tracker and an early refill reminder. I would avoid spending too much time on calculations that do not directly improve the prediction. I would also prioritize collecting genuine cooking records before implementing additional features.

## Where AI Helped

AI helped me plan the project, understand LPG usage estimation, implement the application using JavaScript and Node.js, and improve CSV validation. It was especially useful for debugging, handling invalid records, understanding Git commands, organizing documentation, and preparing the demonstration.

## Where AI Wasted Time

I spent considerable time repeatedly modifying the code and refining documentation. AI-generated cooking records helped me test the application, but they could not replace the genuine observations required by the assignment. Then i somehow take some real records with help from my mother 

## Final Learning

Building GasWise helped me understand that solving a real problem requires more than writing working code. Understanding the user's needs, collecting reliable data, testing assumptions, and acknowledging limitations are equally important. The project taught me to use AI as a development assistant rather than as a replacement for real-world observation.
